# Claude Quickstarts

**[English](README.md)** | **[Tiếng Việt](README.vi.md)**

Claude Quickstarts là một bộ sưu tập các dự án được thiết kế để giúp các nhà phát triển nhanh chóng bắt đầu xây dựng ứng dụng sử dụng Claude API. Mỗi quickstart cung cấp một nền tảng mà bạn có thể dễ dàng xây dựng và tùy chỉnh cho nhu cầu cụ thể của mình.

## Bắt Đầu

Để sử dụng các quickstart này, bạn sẽ cần một khóa API của Claude. Nếu bạn chưa có, bạn có thể đăng ký miễn phí tại [console.anthropic.com](https://console.anthropic.com).

## Các Quickstart Có Sẵn

### Customer Support Agent (Trợ Lý Hỗ Trợ Khách Hàng)

Một trợ lý hỗ trợ khách hàng được hỗ trợ bởi Claude. Dự án này minh họa cách tận dụng khả năng hiểu và tạo ngôn ngữ tự nhiên của Claude để tạo ra một hệ thống hỗ trợ khách hàng có sự hỗ trợ của AI với quyền truy cập vào cơ sở kiến thức.

[Đi đến Customer Support Agent Quickstart](./customer-support-agent)

### Financial Data Analyst (Nhà Phân Tích Dữ Liệu Tài Chính)

Một nhà phân tích dữ liệu tài chính được hỗ trợ bởi Claude. Dự án này minh họa cách tận dụng khả năng của Claude với trực quan hóa dữ liệu tương tác để phân tích dữ liệu tài chính qua chat.

[Đi đến Financial Data Analyst Quickstart](./financial-data-analyst)

### Computer Use Demo (Demo Sử Dụng Máy Tính)

Một môi trường và các công cụ mà Claude có thể sử dụng để điều khiển máy tính để bàn. Dự án này minh họa cách tận dụng khả năng sử dụng máy tính của Claude, bao gồm hỗ trợ phiên bản công cụ `computer_use_20251124` mới nhất với các hành động zoom.

[Đi đến Computer Use Demo Quickstart](./computer-use-demo)

### Browser Tools API Demo (Demo API Công Cụ Trình Duyệt)

Một triển khai tham chiếu hoàn chỉnh cho tự động hóa trình duyệt được hỗ trợ bởi Claude. Dự án này minh họa cách tận dụng API công cụ trình duyệt của Claude để tương tác web, bao gồm điều hướng, kiểm tra DOM và thao tác biểu mẫu sử dụng Playwright.

[Đi đến Browser Tools API Demo Quickstart](./browser-tools-api-demo)

### Autonomous Coding Agent (Trợ Lý Lập Trình Tự Động)

Một trợ lý lập trình tự động được hỗ trợ bởi Claude Agent SDK. Dự án này minh họa mô hình hai trợ lý (initializer + coding agent) có thể xây dựng các ứng dụng hoàn chỉnh qua nhiều phiên, với tiến độ được lưu trữ qua git và một danh sách tính năng mà trợ lý thực hiện dần dần.

[Đi đến Autonomous Coding Agent Quickstart](./autonomous-coding)

## Cách Sử Dụng Chung

Mỗi dự án quickstart đi kèm với README và hướng dẫn thiết lập riêng. Nói chung, bạn sẽ làm theo các bước sau:

1. Clone repository này
2. Điều hướng đến thư mục quickstart cụ thể
3. Cài đặt các dependencies cần thiết
4. Thiết lập khóa API Claude của bạn như một biến môi trường
5. Chạy ứng dụng quickstart
